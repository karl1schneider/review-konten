# Review Konten

Website review konten Instagram KWaS: kreator upload, reviewer klik gambar atau video untuk menaruh komentar, admin mengatur semuanya. Konten yang sudah diposting diarsipkan ke Google Drive.

- Halaman statis (HTML/CSS/JS) di Netlify
- Supabase untuk login, database, file, dan komentar realtime
- Supabase Edge Function `archive` untuk memindahkan file ke Google Drive

Cara setup: lihat [PANDUAN.md](PANDUAN.md).
